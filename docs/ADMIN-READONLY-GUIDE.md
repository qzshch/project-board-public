# 管理手册 · 协作阅读版

本文面向其他本地电脑上的负责人、继承 SE 和执行 Agent。连接同一 Tailscale 私网后，任何协作方均可阅读，不需要全局管理员身份。阅读文档不会授予创建项目、签发身份、查看其他项目或修改服务的权限。

这是管理流程说明，不包含真实项目快照、管理员私有入口或凭据位置。实际项目材料与身份由负责人通过私有渠道另行交付。

## 1. 先确认访问通道

正式入口：http://example-server.example-tailnet.ts.net:18785 。这是 server 上的 Tailscale 私网服务，不是公网网站。另一台电脑需连接同一 tailnet，或获共享该 server 的访问权限，并由网络规则允许访问 TCP 18785。加入网络不等于取得项目身份。

Agent 应使用运行所在电脑的本地终端、curl 或 Python 访问。某些网页搜索/抓取工具在远端执行，即使本地浏览器能访问，也可能无法读取私网地址。详见[连通性排查](/help/connectivity)。

## 2. 创建项目与分配职责

准备[项目初始化定义](/templates/project-init.json)，填清背景、目标/非目标、约束、历史材料和资源入口。由已获授权的实例管理员创建独立项目，再签发该项目的负责人身份。协作 Agent 不需要取得全局管理身份来阅读或准备这些内容。

负责人在本项目登记成员、职责、继承 SE 和任务范围。执行 Agent 使用自己的项目身份；不同项目身份不能互换。只有被明确授予相应权限的身份才能执行管理操作。继承通过正式接受交接完成，不能只修改姓名或转发原负责人凭据。

## 3. 项目框架与渐进式规划

先建立模块，明确目标、职责边界、负责人、输入输出、公共接口、达成路径、风险、未知项和验收标准。模块可从草稿/调研阶段开始，不要求一开始就编造完整任务清单。

研究、采集和规划文档任务先解决明确问题；验收后由 SE 确认研究结论，再登记新的设计方案版本。执行任务绑定已评审的模块版本。未知项未解决、研究来源变化或共享边界未冻结时，不能绕过规划门禁开始开发。

里程碑单独规定阶段目标、路径、进入条件、关联模块/任务、检验方法、阈值、环境和验收负责人。任务完成后仍需实际阶段检验和证据，不能自动宣布里程碑通过。

## 4. 原子任务、依赖和并行

每张任务明确目标、输入/输出、执行角色、允许目录、Git 基线、固定模块/接口/资产版本、硬前置、排他资源、耦合及验收要求。任务包只是派发组合，不替代模块或原子任务。

包含关系、规划前置、执行硬依赖、产物关系和共享修改分别建模；图只展示有依据且已授权的关系。并行前核对写目录、资源、接口及任务就绪情况。领取成功、取得当前范围的回执后再执行。

## 5. 接口、资产与变更

共享接口冻结为不可覆盖的版本，明确负责人、生产/消费方、签名、单位、错误、事务、幂等和兼容规则。跨模块产物边界需双方共同声明冻结接口。没有共享接口时，也应说明依据并由负责人核实。

接口变更先计算直接与反向影响，记录迁移和测试清单，由相关负责人确认后执行；模块和任务显式迁移版本。独立工作可继续推进。

资产默认项目私有。只有来源、许可、敏感性和内容哈希经过审核的通用资产才能显式发布给指定受众；消费方固定版本，提供方更新不自动改变已有任务。

## 6. 交付、返修、合入与运行验收

负责人给执行 Agent 提供当前任务 brief、允许材料、边界和项目身份。Agent 按固定范围实现，运行真实行为与反例检查，保存证据 SHA、实现提交和服务回执，再提交交付声明。

审核、合入、运行验收分别记录。返修引用具体问题与验收标准，重提不会自动关闭问题。范围或输入变化后先由 SE 确认新范围，不自动覆盖旧提交。最终按项目规则归档；凭据和管理员数据不进入普通交付包。

## 7. 其他会话的阅读顺序

1. [负责人 / 继承 SE 操作指南](/help/owner)：完整项目治理与派发步骤。
2. [执行 Agent 操作指南](/help/agent)：接入、领取、交付和返修命令。
3. [模板目录](/help/templates)：可填写的项目、模块、里程碑、接口、任务和交接定义。
4. [任务与身份 API](/help/api)、[治理 API](/help/governance)：请求结构与门禁。

实例安装、服务恢复和私有管理位置属于受控运维内容，仍由实例管理员在自己的授权会话阅读。不要为读取本文而向其他 Agent 转发全局凭据。
