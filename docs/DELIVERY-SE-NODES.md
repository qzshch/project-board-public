# 项目SE节点自助接入：边界

用户要求把节点编排授权下放给项目SE，消除 nodes=[] 时必须等待人类或实例管理员开通的前置。

- 项目owner/se及兼容旧reviewer管理身份可授权、查看、撤销本项目专用接入端；稳定ID按项目命名空间生成。不能借该接口增加其他项目、替换现有密钥或撤销共享节点。
- 网页提供项目接入文件，CLI允许SE使用自己的项目身份及本机配置直接登记本机生成的节点凭据摘要。只有目标机实际探测/心跳后显示在线能力；接收授权不冒充CLI已运行。
- 在已获授权的电脑、目录和CLI范围内，SE可自行编写本机配置并接入，无需额外人类确认。节点仍只在本机配置的根、角色、模型与原生命令许可内工作。SE身份不成为实例管理员、OS管理员或其他机器登录凭据。
- 项目角色允许集由服务端再次核对。旧全局多项目节点和既有绑定/原生Session ID不迁移、不覆盖。节点撤销仅撤销控制面，不伪称原模型和工具已停止，不撤销独立的项目身份。
- 沿用现有编排与接手协议，不新增调度器、模型路由或项目业务任务。同步手册、下载工具包；独立权限与幂等反例、实际SE页面、完整固定输入回归及server发布验证。
