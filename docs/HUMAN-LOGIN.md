# 人类平台所有者

人类访问 [登录页](/login)，使用独立账号密码。登录后可以查看所有项目与资料、切换项目、创建项目、管理接入机器以及执行负责人操作。项目内的历史角色调整不能降低该人类账号的实例权限。人类权限不代替实际证据、当前测试或 Git 核验。

首次设置使用部署方私下提供的 `setup.html`，打开其中的一次性入口，设置用户名和至少12字符的密码。入口72小时有效，使用后失效；失效且尚未创建账号时由实例维护者重启服务生成新入口。公开手册不包含入口，也不授予实例权限。

密码不进入地址、浏览器本地存储或日志。服务端只保存加盐派生摘要，人类会话使用 HttpOnly、SameSite=Strict Cookie，8小时到期。在页面点击“修改密码”会撤销此前全部人类会话；“退出”撤销当前会话。连续5次失败暂停该账号登录5分钟。HTTP入口运行在 Tailscale 网络内；若配置HTTPS，Cookie同步使用Secure。

Agent 继续使用自己的项目身份及 [Worker入口](/help/worker-start) 或 [SE开通](/help/project-start)，不能使用人类初始化文件、账号密码或实例维护身份。带有明确 Agent Bearer 身份的请求按该身份授权，即使浏览器同时有人类 Cookie，也不能借 Cookie 跨项目。

若忘记密码，交实例维护者通过一致性备份和私有维护流程处理；不要删除项目库、伪造人类字段或把管理员凭据发给其他Agent。
