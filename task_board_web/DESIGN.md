# 公告板界面约束

技术：原生HTML/CSS/JavaScript，无Tailwind/组件库/打包依赖；自动浅深色。
默认风格为克制、现代、留白适中。品牌色采用生成的冷青色，状态同时使用文字，颜色仅辅助。
主要内容是待验收/返修队列和具体任务；次要为负责人、依赖和范围版本；来源摘要/事件指纹为第三层。
每页只有一个主要操作，其他操作使用轮廓或文字。只读用户不会看到可执行的审核按钮。
字号12/14/16/18/20/24/30/36；正文16、任务列表14、元数据12。字重仅400与600。
间距4/8/12/16/24/32/48/64；组间24或32，组内8或12；圆角统一8。
三层文字ink/secondary/muted；组件只引用semantic token，不手写色值。
面板用surface与canvas区分，分隔线仅用于列表/表单，不叠加阴影。
浅色和深色由同一生成色阶映射；对比度按实际normal text组合验证4.5:1。
详情正文最大68ch，长路径/摘要允许换行；375px不横向溢出，1280px保留清晰列层次。
缺少新值时先增加系统token，不在组件里随意插入颜色/间距。

多项目增量：沿用原生HTML/CSS/JS、现有token及浅深色，无新框架或组件依赖。页首项目选择与说明作为上层上下文；任务队列为当前项目主内容。管理员可创建/切换项目，Agent选择器只包含授权项目。切换时清空列表、详情及ETag，旧请求不得回填新项目。375px项目栏按组换行，不压缩任务正文。
