# WeftBoard contributor instructions

Read README.md, the applicable operating guides and relevant tests before changing behavior.
Preserve project, task, event and native session identities. Keep credentials, live state, raw research and execution records outside Git.
Use isolated fixtures for tests. Verify permissions, fixed inputs, evidence and actual execution outcomes; never fabricate a pass.
Use explicit interface versions and review affected consumers before shared changes.
Run appropriate checks, clean owned temporary processes and files, and update documentation.
Production configuration belongs to the deployment owner; examples are not credentials or deployment instructions for a particular machine.
